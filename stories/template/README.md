# 工作时间之外｜伯贤的手机 · 迁移试玩版

这是在 FoundPhone Studio 原有 Runtime、App 界面、事件引擎上制作的原创虚构故事，不是现实社交客户端，也不代表现实人物的私人生活。

## 本版

- 保留框架代码和原有空白、测试入口。
- 31 个剧情节点，136 个事件，4 条经过引擎回放验证的结局路径。
- 开局选择名字、起始日期和手机密码。姓名使用 `{{player}}` 标记，在运行前统一替换；日期按真实公历偏移，保存后不会因现实时间变化重新定位。
- KakaoTalk 使用现有联系人和会话。现场段落放在备忘录「现场」，选项后的完整对白放在「回应记录」。消息通知也会显示即时回应。
- Instagram 和 X 包含多个虚构账号；保留原文及预写中文翻译可选。完整主剧情目前仅中文，不声称完整韩文界面。
- 点刷新会重新排列已有故事帖子，不请求现实平台，也不会伪造实时动态。
- 评论、壁纸和玩家存档遵循原框架的浏览器本地保存方式；不是联网多人论坛。
- Spotify 只提供歌曲信息，没有附带歌曲音频，也不声称真实播放。

## 公开范围

只包含原创剧情和代码。未导入付费 Bubble 原始记录、原音视频、私人聊天、真实账号密码、访问密令或未授权人物图片。未来添加素材前应另行确认公开使用权。
